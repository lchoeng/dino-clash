# Dino Clash: Linus & Ava

A 16-bit arcade beat-'em-up in a single HTML file. Pick Linus or Ava and fight through three stages of dinosaurs: Airbase Docks, Jurassic Coast and Lagoon Citadel.

## Play
Open `index.html` in a browser, or turn on GitHub Pages for this repo.

## Controls
| Action | Keyboard | Touch |
|---|---|---|
| Move | Arrows / WASD | D-pad |
| Jump | Up / W (tap) | ▲ |
| Attack | Z / J | ATK |
| Special 1 | X / K | SP1 |
| Special 2 | C / L | SP2 |
